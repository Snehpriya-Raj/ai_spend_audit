# AI Spend Audit

AI Spend Audit is a modern AI cost optimization web application that helps users analyze and reduce their spending on AI tools like ChatGPT, Claude, Cursor, Gemini, and GitHub Copilot.

It provides real-time audit results, savings recommendations, and stores data using Supabase for analytics.

---

# 🚀 Features

- AI tool expense analysis
- Smart savings recommendation engine
- Instant audit generation
- Monthly & annual savings calculation
- Dynamic dashboard with real data
- Responsive modern UI (Tailwind CSS)
- Supabase database integration
- Contact + Pricing + Feature sections
- Mobile-friendly navbar

---

# 🧠 How It Works

1. User selects AI tool (ChatGPT, Claude, etc.)
2. Enters monthly spend, team size, and use case
3. Clicks **Generate Audit**
4. System calculates:
   - Savings estimate
   - Recommendation
   - Annual projection
5. Data is saved to Supabase database
